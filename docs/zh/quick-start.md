# 快速开始

[文档首页](../README.md) · [English](../en/quick-start.md)

1. 从[正式发布页](https://github.com/WECLwhy/AstraCreate/releases/latest)下载 PKG；需要 macOS 13+ 和 Apple Silicon。
2. 完成系统安装器的授权和安装，再打开 `/Applications/AstraCreate.app`。
3. 在系统设置中启用“新建常用文件”Finder 扩展。菜单没出现时看[排障](finder-troubleshooting.md)。
4. 打开普通本地文件夹，在空白处右键 → 新建文件，或点击 Finder 工具栏的 AstraCreate 图标。
5. JSON 等新增格式默认关闭，在“常用设置 → 开发文件”逐项开启。

![开发文件设置](../screenshots/developer-files.png)

修改会自动保存，重新打开菜单生效。设置窗口左侧可切换常用设置、外观、诊断与支持。完整[安装指南](installation.md)、[兼容性表](../compatibility.md)和[文件格式说明](features.md)可供查阅。
