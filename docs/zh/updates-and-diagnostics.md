# 更新、诊断与常见问题

[文档首页](../README.md) · [English](../en/updates-and-diagnostics.md)

## 检查更新

“诊断与支持 → 检查更新…”手动获取 GitHub 最新正式版元数据，不定时后台检查。发现更高版本后显示版本、大小及说明。只有点击“下载并安装…”才获取安装包和必要校验文件；可选择稍后或取消下载。

来源、大小、PKG 标识及 SHA-256 必须通过；缺少有效校验信息会停止自动更新，并提供发布页。校验通过后打开 macOS 安装器，由用户完成系统授权及安装，再重新打开 App。**打开安装器不等于安装成功。** 不自动降级，也不绕过系统安全检查。

## 导出诊断

复现后点击“导出诊断日志…”，手动选择位置保存一个 JSON。包含软件/系统版本、扩展状态、近期结构化事件；每组件有大小限制，不含用户路径、文件内容或剪切队列，不自动上传。缺失/不可读组件会标明状态，不代表组件正常。

分享前自行检查文件及截图。不要附带历史原始日志、完整容器或 `clipboard.json`。详见[隐私说明](../../PRIVACY.md)。

## FAQ

- **JSON 等菜单没显示？** 新格式默认关闭，先到开发文件分组开启，再检查新建文件子菜单。
- **透明度变化不明显？** 系统“减少透明度”、当前浅深模式、正在编辑的方案和背景都会影响材质。
- **.ts 显示媒体类型？** Finder 的类型说明和默认打开应用取决于本机文件关联；文件仍以 .ts 及 UTF-8 创建，本工具不会强制接管关联。
- **微信下载的文件只读？** 本版不改第三方下载文件权限。先核对来源、编辑权和文件权限；不要批量放宽权限。
- **支持其他系统或 Intel 吗？** 参见[兼容性表](../compatibility.md)。
- **发现安全问题？** 使用[私密漏洞举报](https://github.com/WECLwhy/AstraCreate/security/advisories/new)，不要公开上传凭据或可利用细节。
