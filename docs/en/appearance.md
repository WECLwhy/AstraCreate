# Appearance and personalization

[Guide home](../README.md) · [中文](../zh/appearance.md)

1. Select Appearance, then Follow System, Light or Dark.
2. Choose the light/dark palette to edit. They save independently; switch display mode to preview.
3. Glass transparency ranges from 0–100%. It adjusts panel tint opacity, not the opacity of the entire window or text.
4. Set sidebar accent and glass tint through native color wells or `#RRGGBB` entry. Invalid HEX is not saved.
5. Reset This Palette affects only the palette being edited and retains other preferences.

![Light appearance; Chinese UI](../screenshots/appearance-light.png)
![Dark appearance; Chinese UI](../screenshots/appearance-dark.png)

Changes apply and save immediately. Reduce Transparency takes priority; native switch colors remain system-controlled. Materials depend on the backdrop and OS. Language controls remain in the sidebar footer.
