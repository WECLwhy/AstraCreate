# 行为准则 / Code of conduct

本项目欢迎不同经验、语言和背景的贡献者。请友善讨论具体问题，尊重他人时间，接受建设性反馈。禁止骚扰、歧视、人身攻击、威胁、未经同意披露个人信息以及发布垃圾信息。行为准则适用于 Issue、PR、Wiki 和其他项目交流空间。

Contributors of all backgrounds, languages and experience levels are welcome. Discuss concrete problems respectfully, value others' time and accept constructive feedback. Harassment, discrimination, personal attacks, threats, non-consensual disclosure of personal information and spam are not acceptable. This applies to issues, PRs, Wiki and other project spaces.

维护者可以编辑或移除违规内容、关闭失去建设性的讨论，并按情况限制参与。需要举报时使用 GitHub 的 [Report abuse](https://github.com/contact/report-abuse)；不要公开重复发布私密或有害内容。对维护者行为的投诉也可提交给 GitHub。

Maintainers may edit/remove violating content, close unproductive discussions or restrict participation as appropriate. Use GitHub [Report abuse](https://github.com/contact/report-abuse) for reports, including concerns about maintainer conduct. Do not repost private or harmful material publicly.
